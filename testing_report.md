# Отчет по тестированию ya.ru 🧪

## Задание 1. Тест-кейсы на переход к странице поиска

**Предусловия:**
* Открыт браузер на компьютере.
* Открыта главная страница `ya.ru`.
* Пользователь имеет стабильное интернет-соединение.

| № | Название тест-кейса | Шаги | Ожидаемый результат |
| :--- | :--- | :--- | :--- |
| **1** | Переход к выдаче через `Enter` | 1. Кликнуть в строку поиска. <br> 2. Ввести запрос "коты". <br> 3. Нажать `Enter` на клавиатуре. | Пользователь перенаправлен на страницу результатов поиска по запросу "коты". |
| **2** | Переход к выдаче через кнопку поиска | 1. Кликнуть в строку поиска. <br> 2. Ввести запрос "коты". <br> 3. Нажать кнопку поиска (лупа). | Пользователь перенаправлен на страницу результатов поиска по запросу "коты". |
| **3** | Переход к выдаче через выбор подсказки | 1. Кликнуть в строку поиска. <br> 2. Ввести "коты". <br> 3. Кликнуть по подсказке "коты воители" в выпадающем списке. | Пользователь перенаправлен на страницу результатов поиска по запросу "коты воители". |

## Задание 2. Исследовательское тестирование бесконечной ленты

В процессе тестирования ленты контента на `ya.ru` были выявлены следующие моменты:

#### 1. Дефект: Отсутствие индикатора загрузки при скролле
* **Описание:** При очень быстром прокручивании ленты вниз не всегда отображается индикатор загрузки.
* **Почему это проблема:** Пользователь не понимает, зависла ли страница или контент еще подгружается.

#### 2. Риск: Неактуальность рекомендаций
* **Описание:** В ленте иногда отображаются товары или статьи, которые не соответствуют интересам пользователя.
* **Почему это риск:** Снижается вовлеченность пользователя и время, проводимое на странице.

#### 3. Баг: Наложение элементов при быстром скролле
* **Описание:** При крайне быстром прокручивании ленты на десктопе иногда происходит наложение контентных карточек друг на друга.
* **Почему это проблема:** Визуальный дефект верстки, снижающий доверие к качеству продукта.
